## 主张

自动化 harness 工程卡在三件事：动作空间杂、轨迹太长、编辑难归因。AHE 用三根可观测性柱子：

1. **组件** — 七类可编辑件都是文件，动作可逆。
2. **经验** — 百万 token 轨迹蒸馏成分层证据，evolver 不啃生 log。
3. **决策** — 每次编辑带自报预测，下一轮用任务结果证伪；无效则按文件回滚。

十轮把 TB2 pass@1 从 69.7% 拉到 77.0%，超过 Codex-CLI（71.9%）和 ACE。冻结后的 harness 能转到 SWE-Verified 与其他模型族。消融：**工具 / middleware / 长期记忆** 带走增益，**只改 system prompt 会回退**。

## 对 Yoyo 的含义

CAS 已经把组件变成内容寻址对象，接近「文件级可逆」。缺的是决策柱：`Proposal.PredictedFixes` 写了，Harbor 没有拿它逐条对账。journal 是证据平面的雏形。

「只改 prompt 会回退」支持我们把 L1 扩到 skill / middleware，而不是把 evolve 做成写长 system prompt。

## 可偷 / 应拒

- 偷：change manifest；失败则文件级回滚（我们已有 snapshot rollback）；不要只进化散文。
- 拒：让 evolver 改七类里属于 L3/L4 的那些（loop 拓扑、eval）。
