## 主张

部署轨迹不该只拿去微调模型。Harness-R1 把「根据失败改可执行 runtime」做成 **学出来的能力**：单独的 9B harness 工程师用在线 RL（先 SFT 冷启动，再 GRPO），奖励来自冻结目标智能体在同一 batch 上的重跑。WebShop / ALFWorld / DBBench 上 Qwen3.5-9B 从 44.3% 到 53.6%；目标再微调之后还能再涨。

## 对 Yoyo 的含义

产品不训练工程师模型。思想对齐的是：补丁的奖励必须是 **同一批任务重跑的真实结果**，不是模型自评。这就是 Harbor。不要为了追这篇去加 GPU 训练环。

## 可偷 / 应拒

- 偷：失败条件化的补丁；用重跑结果当奖励。
- 拒：在桌面 agent 里跑 RL 训练。
