## 主张

Gödel 机要求「可证有益」才能自改，实际上不可证。DGM 用经验验证替代证明：维护 coding agent 档案，采样一个父代，让基础模型长出新版本，开放式地长成一棵多样的树。SWE-bench 20%→50%，Polyglot 14.2%→30.7%。安全措施包括沙箱与人监督。进化对象包括智能体 **自己的代码**（编辑工具、长上下文管理、互审机制）。

## 对 Yoyo 的含义

`SelectParent` / `ParentWeight` 是 DGM 档案采样的缩小版。快照 `parent` 指针 + lineage UI 让这棵树可见，而不是黑盒版本号。

关键收窄：档案里的节点是 **harness 快照**，不是 Go 源码。评测器不能当父代。这是对「开放式自改代码」的产品否决。2026 的 HSI 用冻结外锚处理同一恐惧；我们用 L4。

## 可偷 / 应拒

- 已偷：archive、按质量与开放度采样、经验验证。
- 拒：让 agent 改自己的实现代码。
- 2026 对照：HarnessBank 用语义基因库批评贪心档案；若树塌缩再考虑换采样，而不是换进化对象。
