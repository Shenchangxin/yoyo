## 主张

长视频理解不只取决于 VLM，还取决于如何从更长的视频里 **构造** 有限上下文。现有系统把采样 / 检索 / 记忆 / 控制写死，构造程序本身很难当成优化对象。VideoHarness-RSI 冻结回答模型与接口，递归搜索可执行的上下文构造器。弱初始化（均匀采样）与强初始化（已有人工 AKS harness）都能再往前走。优势在匹配的视觉 token 预算下保持，并能直接转到其他长视频基准。

## 对 Yoyo 的含义

Yoyo 不是视频产品。有用的句子只有一句：**可执行的上下文构造是单独一层。** 这正是 `runtime.Shape`：只读投影、spill、microcompact、snip，明确「LLM 摘要不是 Shape 的一部分」。

若 evolve 开始碰 compaction 策略，那是 L3（loop 拓扑），需要人确认。VideoHarness-RSI 提醒我们：不要把 Shape 藏进 prompt 散文里，要保持它是可差分的程序。

## 可偷 / 应拒

- 偷：上下文构造与答题模型解耦；弱/强两种初始化都做 RSI。
- 拒：用 LLM 摘要替换 spill（与 Shape 的设计相反）。
