## 主张

自改代码的智能体若只按当前 SWE 分数扩树，会错过「后代其实更会自我改进」的分支（metaproductivity–performance mismatch）。HGM 用 clade 的 CMP（后代基准分聚合）指导搜索。SWE-Verified / Polyglot 上超过先前自改进方法；在 SWE-Lite + GPT-5 上声称达到人写 coding agent 的官方成绩。

## 对 Yoyo 的含义

CMP 是 DGM `ParentWeight` 的亲戚：不要只宠当前高分节点。我们采样已经用 `score/(1+children)`。不要把 HGM 的「改 agent 源码」搬过来 — ICLR 2026 接收不改变 L4。

## 可偷 / 应拒

- 可看：后代质量，不只当前分（transfer 失败降权已经是弱 CMP）。
- 拒：自改 Go。
