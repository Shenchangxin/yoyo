## 主张

对 Claude Code 公开源码做架构还原，并与 OpenClaw、Hermes 对照。五个价值取向（人的决策权、安全隐私、可靠执行、能力放大、情境适应）经十三条原则落到实现。Loop 本身是 while；代码量在周围：七种权限模式 + ML 分类器、五层 compaction、MCP/plugins/skills/hooks、subagent、append-only session。三个系统在「周界权限 vs 每步审批 vs 多表面审批」上给出不同答案。文末六个开放方向。

## 对 Yoyo 的含义

对照而不是模仿：

| Claude Code（该文） | Yoyo |
| --- | --- |
| 七模式 + 分类器 | Once/Session/Always + NeverAlways；无隐藏分类器 |
| 五层 compaction | Shape：spill / microcompact / snip；LLM 摘要只在 checkpoint，且不碰 playbook |
| 四种扩展 | skills + MCP + 签名 WASM；hooks 很少 |
| 隔离 subagent | depth-1 `task` |
| append-only session | JSONL + hash-chain journal |

人的决策权：L3 确认、审批画在 transcript 里，与「human decision authority」同向。我们拒绝把危险动作交给不可见的分类器（威胁模型要可审计）。

## 可偷 / 应拒

- 偷：把价值观写成可测试的实现选择；compaction 分层；subagent 隔离。
- 拒：ML 审批分类器；27 个 hook 事件的兼容层。
- 已对齐：单 loop；权限；skills 渐进披露。
