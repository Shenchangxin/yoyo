## 主张

RSI 的瓶颈常常是探索：固定策略不随搜索空间长大，在线改策略又要在长程 rollout 上付延迟又贵的反馈。Dream-RSI 加一层轻量编排，**不改底层 coding agent**。把历史发现树当成对已实现搜索空间的 replay 模拟器，「做梦」拿即时 off-policy 反馈来改探索策略，再部署回线上，扩大模拟器池。算法工程 / 数学优化 / GPU kernel 上，发现质量持平或更好，若干设置成本明显下降。

## 对 Yoyo 的含义

模式有用：进化对象可以是 **探索策略**，执行 agent 冻结 — 这接近我们「frozen loop topology、进化的是 playbook」。不要把世界模型做进桌面助手。

若以后做「在进化档案上离线打分提案」而不每次都跑满 Harbor，那就是这篇的做梦：用已有 trial 树当模拟器。现在 archive 还太小，不够格。

## 可偷 / 应拒

- 偷：冻结执行 agent，进化编排；用历史树做便宜反馈。
- 拒：为 RSI 引入独立世界模型训练。
