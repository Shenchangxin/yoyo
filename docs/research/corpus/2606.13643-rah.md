## 主张

RLM 的递归单位是「无工具的模型调用」。生产 coding agent 开始用代码拉起子智能体。RAH 把递归单位定义成 **整份 harness**（文件系统、代码执行、规划）。父代理写脚本并行 spawn 子 harness，小任务才走结构化函数调用。GPT-5 固定时，Oolong-Synthetic 上相对 Codex 基线 71.75% → 81.36%，增益归 harness 不是模型。

## 对 Yoyo 的含义

我们 **depth-1** `task` 是故意的：无限 harness 递归是 L3 拓扑，也放大权限面。长上下文办公任务（inbox、长 PDF）可以以后用「父写脚本、子只读」的受限 RAH，但默认不要打开。

## 可偷 / 应拒

- 偷：递归单位是 harness 不是裸模型；评测时固定骨干。
- 拒：无界深度；子代理继承父的 `send_as_you`。
