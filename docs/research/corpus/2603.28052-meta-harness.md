## 主张

Harness 是决定「存什么、取什么、给模型看什么」的代码，仍多半手写。文本优化器把反馈压成标量或短摘要，配不上长程失败。Meta-Harness 用 **coding agent 当 proposer**：所有历史候选的源码、分数、轨迹放在文件系统里，用 grep/cat 按需读（中位 82 个文件/轮），而不是塞进一个 prompt。TB-2 上发现的 harness 超过 Terminus-KIRA（Opus 4.6），Haiku 4.5 报告第一；分类与 IMO 级数学上也有跨模型迁移。

ICML 版本标题强调 **post-training the surrounding agent system**。

## 对 Yoyo 的含义

可偷：evolve archive 已经有节点，但 proposer 拿到的是密封 JSON 包，不是「自己去翻 trial 目录」。把 trial 日志做成可 grep 的证据平面（held-out 正文仍剥离）是合法的下一步。

应拒：让 proposer 看到评测器实现、安全套件源码、vault。文件系统搜索一旦没有 jail，就是威胁模型里的 eval gaming。

## 可偷 / 应拒

- 偷：证据在文件系统、按需检索；proposer 是 agent 不是填空模型。
- 拒：进化 harness **代码**（Go）；把 evaluator 放进可搜索树。
