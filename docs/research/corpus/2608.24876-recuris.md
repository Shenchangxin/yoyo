## 主张

长程 RSI 失败常常是历史把任务状态淹没、技能调用错位。Recuris 拆成工作记忆（跟踪进度、选择技能）与经验记忆。固定 Meta-Agent 把执行证据变成对 Skill Memory 的 **局部、过验证门** 的更新。四个长程基准 × 十个模型，37 对中 35 对成功率上升；horizon 越长优势越大。

## 对 Yoyo 的含义

个人 OS 的 Memory 表面已经规定：模型自选的「重要事实」不得未过 Harbor 就晋升。Recuris 把这件事说成架构：技能库可以长，但更新必须局部且过门。不要让 Meta-Agent 直接写 `refs/active`。

与 SKILL.state 互补：一个管 skill 内部状态，一个管选哪个 skill。

## 可偷 / 应拒

- 偷：工作记忆 vs 经验记忆；技能更新局部化 + 验证门。
- 拒：无门的自生成技能库（SoK 已警告会降成功率）。
