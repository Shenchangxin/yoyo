## 主张

Composer 2 是为 agentic SWE 特化的模型。两阶段：继续预训练（从 Kimi K2.5 MoE）+ 大规模 RL。核心教条： **在部署用的同一套 Cursor harness 里训练**，工具与结构等价，以减小 train–test mismatch。公开数字（他们的 harness）：Terminal-Bench 61.7，SWE-bench Multilingual 73.7。第三方模型用「我们的 harness / 官方自报」双列，承认 harness 会改分数。

## 对 Yoyo 的含义

Yoyo 明确不是 Cursor 克隆，也不训模型。仍有两句用得上：

1. 评测必须声明 harness。`yoyo eval` 已经绑定 snapshot hash。对外数字要带上哈希，否则不可比。
2. RHI 的共进化命题：今天的干净轨迹是明天某次 RL 的数据。journal 与 spill 保持无损，是我们能为那条未来付的最大成本。

不要把 Composer 的「在 Cursor 里训」读成「Yoyo 也该绑死一家模型」。指纹 refs 的存在就是为了换模型时换 harness。

## 可偷 / 应拒

- 偷：数字带 harness 身份；训练/评测环境同源（对我们 = eval 用与聊天同一套 loop）。
- 拒：为了追 SWE 榜去做模型训练或云端 rollout 农场。
