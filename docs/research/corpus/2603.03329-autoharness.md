## 主张

模型当 agent 时常做出环境 **禁止** 的动作（Kaggle GameArena 上 Gemini-2.5-Flash 78% 的棋负来自非法着）。AutoHarness 用环境反馈做少量迭代，让较小模型 **合成代码 harness**（合法动作过滤器），在 145 个 TextArena 游戏上挡住全部非法着，并超过更大的 Gemini-2.5-Pro。极限情况：整份策略编译成代码，推理时不再调用 LLM。

## 对 Yoyo 的含义

这是 Google/DeepMind 作者线上、ICLR RSI workshop 的代表作，但对象是游戏合法性，不是 SWE harness。Yoyo 的 capability broker 已经是「非法动作进不了环境」的工程对应物。不要走「把整个 agent 编译成无 LLM 策略」——个人工作站的任务不是封闭规则游戏。

## 可偷 / 应拒

- 偷：用环境反馈合成 **守卫代码**，而不是再写一段「请不要非法操作」的 prompt。
- 拒：用合成策略替换 ReAct loop。
