## 主张

Skill 不是一次性计划和原子 tool call。它是带适用条件、执行策略、终止条件、可复用接口的程序能力。SoK 覆盖发现→练习→蒸馏→存储→组合→评价→更新的生命周期。两套分类：七种系统模式（从 metadata 渐进披露到市场分发）；表示 × 范围（自然语言 / 代码 / 策略 / 混合 × web/OS/SWE/机器人）。

安全部分用 ClawHavoc 战役：约 1200 个恶意技能进入大型 agent 市场，拖走 API 密钥、钱包、浏览器凭据。评价上：精选技能能抬成功率，**自生成技能可能降低成功率**。

## 对 Yoyo 的含义

渐进披露已经做了：pins 里只有 catalog line，`load_skill` 才进正文。WASM 无 WASI FS、未签名不能 checkout 到 active，是对 ClawHavoc 类攻击的正确默认。

「自生成技能可能变差」直接约束 evolve 的 skill 表面：新 skill 必须过 Harbor，不能因为「模型觉得这是个好说明书」就晋升。这与 ACE「不整页重写」同构。

## 可偷 / 应拒

- 偷：信任分层；市场默认有毒；自生成技能强制评测。
- 拒：开放未审计的 skill marketplace 写进 `refs/active`。
- 下一刀：可执行 skill（Pattern-2）走已有 WASM 通道，不要用 shell 脚本当 skill body。
