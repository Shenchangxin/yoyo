# Notifications & Toasts

| Channel | For |
|---|---|
| sonner toast | Saved, copied, eval finished |
| Inline Alert | Missing workspace/key, Harbor safety fail |
| Native notification | Turn complete while unfocused (already in Go chrome) |

- Promise toasts for Harbor/Evolve runs.
- Undo for reversible hunk apply when possible.
- Do not toast every stream token.
- Live region required (sonner).
