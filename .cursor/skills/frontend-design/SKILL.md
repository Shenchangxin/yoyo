# Frontend Design

Approach this as the design lead for a client who already rejected cliché templates. Make deliberate choices. For Yoyo, the committed world is a **desktop agent workstation** (Codex/Work Buddy grammar), not a ChatGPT marketing clone and not Anthropic cream/terracotta.

## Ground in the subject

Yoyo is a local harness workstation: threads, live transcript, composer, review, Harbor/Evolve/Harness labs. Materials: zinc surfaces, CAS hashes, eval gates, diffs. Audience: the operator of one agent loop.

## Design principles

- Typography carries personality. One family, clear scale. Do not accent a single word in a headline.
- Visual structure encodes information, not decoration.
- Motion only to answer an action or show state.
- Copy is design. Empty and error states give a next step.

## Defaults to avoid unless the brief pins them

1. Warm cream + terracotta serif (Claude-template tell).
2. Near-black + acid green/vermilion accent with no workstation density.
3. Broadsheet hairline newspaper layout.
4. SaaS-card kit: identical rounded cards, same shadow, gradient washes.
5. Tracked-out ALL-CAPS eyebrows, middle-dot meta strings, monospace costume labels.

Yoyo already pinned a ChatGPT-like zinc+teal look. That is a starting costume, not the destination. Keep the three-pane IA; spend craft on density, review, and laboratory precision rather than Sparkles empty states.

## Process

1. Compact token system: 4–6 named colors, type roles, layout concept, principles.
2. Review against the brief: if it looks like the generic AI chat you would emit for any product, revise.
3. Then code. Critique: remove one accessory.

## Quality floor

Responsive to a usable desktop minimum (~1100px three-pane, collapse inspector below that). Visible keyboard focus. `prefers-reduced-motion`. Contrast. Harmonious palette.
