# Operate mode

App UI, settings, transcripts, tools. Familiarity is a feature. The tool should disappear into the task.

## Product slop test

A category-fluent user must trust the interface immediately. Failure is strangeness without purpose: over-decorated buttons, mismatched forms, gratuitous motion, display fonts on labels.

## Typography

- One well-tuned sans for headings, buttons, labels, body, data.
- Fixed rem scale, not fluid clamp headings.
- Scale ratio 1.125–1.2. Prose 65–75ch; tables may run denser.

## Color

- Restrained. Accent only for primary actions, current selection, and state.
- A second neutral layer for sidebar/inspector vs the transcript surface.
- Full state vocabulary: hover, focus, active, disabled, selected, loading, error, warning, success.

## Components

Every interactive control: default, hover, focus, active, disabled, loading, error.
Skeletons for content regions. Empty states that teach. Overlays in a portal so they are not clipped.

## Motion

150–250ms. Conveys state, not decoration. No orchestrated page-load sequences.

## Permissions

System/familiar sans, standard nav (sidebar + command palette), density, consistency over surprise.
