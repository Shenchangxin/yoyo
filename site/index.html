Inside the window 窗口里有什么 窓の中身

A client of one Go loop. Not an IDE. 同一条循环上的客户端。不是 IDE。 ひとつのループのクライアント。IDE ではない。

Files stay in a folder you pick. Keys stay in a local vault. Agent chat and Video chat are separate session channels. Opening Control hides the thread rail — the agent cannot change those settings. 文件在你指定的文件夹里，密钥在本地保险库。Agent 对话和视频对话走两条会话通道。打开设置会收起会话轨——外观、策略、更新器，Agent 碰不到。 ファイルは選んだフォルダ。鍵はローカル保管庫。Agent と Video は別チャネル。設定を開くとレールが隠れる。エージェントはそこを触れない。

Agent
Turns against a local workspace. @file / @folder / @harness are budgeted injections — not a repo dump. Plan is a composer chip: it proposes, it does not write. Stop cancels the in-flight turn and keeps partial output. 对着本地工作区跑一轮。@file / @folder / @harness 是有预算的注入，不是把整仓塞进提示词。Plan 是输入框上的芯片：只提议，不动手。Stop 取消进行中的一轮，已写出的会留下。 ローカル作業フォルダに対するターン。@file / @folder / @harness は予算つき。Plan はチップで、提案するだけで書かない。Stop は途中まで残す。
Video 视频 ビデオ
Create, Drama, and Canvas share one chrome. Drama chat is home; the episode board is an on-demand director desk. Video has its own default folder so it does not mix with Agent workspaces. More 创作、短剧、画布共用一套壳。短剧对话是首页；分集板是按需打开的导播台。视频有自己的默认目录，不和写代码的工作区搅在一起。展开 Create / Drama / Canvas は同じクロム。Drama の会話がホーム。話数ボードは必要なときだけ。Video は専用フォルダ。続き
Skills 技能 スキル
A catalog plus Packs — versioned skill trees such as Superpowers, installed under ~/.yoyo/packs/. Packs stay off until you enable them for the workspace. Harbor never loads them. More 目录，加上 Pack：像 Superpowers 这样的整棵技能树，装在 ~/.yoyo/packs/。默认关，工作区里你打开才进会话。Harbor 评测从不加载这些包。展开 カタログと Pack。Superpowers などは ~/.yoyo/packs/。既定オフ。ワークスペースで有効化。Harbor は読み込まない。続き
Harness
One RSI workspace: Overview → Propose (Evolve) → Prove (Harbor) → Promote. Chat docked there is opt-in. It is not a sibling of Agent with equal weight. More 一个 RSI 工作区：总览 → 提议（Evolve）→ 证明（Harbor）→ 晋升。那里的对话是可选停靠，不是和 Agent 平级的另一个聊天。展开 Overview → Evolve → Harbor → Promote。そこのチャットは任意。Agent と同等の兄弟ではない。続き
Control 设置 設定
Vault, models, policy, USD budget hard-stop, wallpaper, updater. Connections (chat, image, video, speech, search, storage) are JSON under ~/.yoyo/connections. Keys never leave the vault. 保险库、模型、策略、美元预算硬停止、壁纸、更新器。连接（对话、图像、视频、语音、搜索、存储）是 ~/.yoyo/connections 里的 JSON。密钥不进我的服务器。 保管庫、モデル、ポリシー、USD 上限、壁紙、アップデータ。接続は ~/.yoyo/connections。鍵は外に出ない。
Companion 桌面伴侣 コンパニオン
A desk pet beside the main window. Tray toggle, no taskbar slot. Notifications land on the pet. Click-through chrome, so it does not steal the desktop. 和主窗口一起待在桌面上。托盘一个开关即可显示或隐藏，不占任务栏。通知会打到宠物身上。点击可以穿透壳层。 メイン窓の横のデスクペット。トレイで出し入れ。タスクバーは占有しない。通知はペットへ。

Human gate 人闸 人のゲート

The agent asks. You decide. 它开口问。你拍板。 エージェントは尋ねる。決めるのはあなた。

Write a file, run a command: once, this chat, always, or deny. Approvals render in the stream. Review is a queue mirror, not the only Once/Deny surface. Desktop defaults to ask — not auto-allow. 写文件、跑命令：一次、本会话、永远，或拒绝。审批就画在对话里。右侧审查是队列镜像，不是唯一的闸。桌面默认是问你，不是全自动。 書き込みもコマンドも、一度・この会話・常に・拒否。承認はストリームに出る。既定は尋ねる側。

One window 同一个窗口 ひとつの窓

Speak, watch, review. 左边说，中间看，右边审。 話す。見る。審査する。

01

Pin a file, not the repo 钉一份文件，不是整仓 リポジトリではなくファイルをピン

@file and @folder are budgeted injections. Typing @ does not dump the tree into the prompt. @file / @folder 是有预算的注入。打一个 @，不会把目录树塞进提示词。 @file と @folder は予算つきの注入。@ を打っただけでリポジトリは入らない。

02

The loop can wedge. The window cannot. 循环卡住，窗口还得活着。 ループが詰まっても、窓は生きている。

Tools stack in the same turn — glob, grep, apply_patch, git, shell. Set YOYO_ISOLATE=1 and the desktop talks to a worker, so a stuck model does not freeze the shell. Depth-1 task subagents nest in the parent transcript. 工具过程叠在当前这一轮：glob、grep、apply_patch、git、命令。设 YOYO_ISOLATE=1，循环丢到子进程，界面死不了。一层 task 子代理会嵌在父对话里。 ツールは同じターンに積む。YOYO_ISOLATE=1 ならワーカーへ。深さ 1 の task サブエージェントは親の転写にネストする。

03

Review is a queue, not a tab 审查是队列，不是另一个页 審査はタブではなくキュー

Hunks you tick and apply, an isolated browser for pages the agent opened, a trajectory. Feel boxed in — pop the page into the system browser. 补丁可以勾选再应用；Agent 打开过的页出现在隔离浏览器里；还有轨迹。内嵌窗口别扭，可以丢到系统浏览器。 ハンクを選んで適用。隔離ブラウザ。軌跡。狭ければシステムブラウザへ出せる。

04

A thread is an object 会话是对象，不是一串气泡 スレッドはオブジェクト

Search, rename, running indicator. Fork copies the JSONL and starts a new chat — it does not move refs/active. Hover your turn: copy, restore files from this turn, fork from here. Restore fails loud if it cannot find the files. It does not rewind the repo in silence. 可搜索、可改名、有进行中指示。分叉是复制 JSONL 开一条新会话，不会动 refs/active。悬停自己的那句：复制、还原这一轮文件、从这里分叉。找不到落点就报错，不会偷偷整库回滚。 検索、改名、実行中。Fork は JSONL のコピー。refs/active は動かない。自分のターンから復元・分岐。見つからなければ失敗する。

05

Budget is a hard stop 预算是硬停止 予算はハードストップ

A USD cap in Control. When it hits, the loop stops. Not a dashboard warning you can ignore. 设置里的美元上限。到点就停，不是可以忽略的提示条。 設定の USD 上限。達したら止まる。無視できる警告ではない。

Harness

Prove it, then promote. 先证明，再晋升。 証明してから昇格。

Most agents get “smarter” by shipping a longer prompt. Yoyo treats the harness the way Git treats source: content-addressed objects, mutable pointers, tests before merge, a human gate. Online thumbs write refs/staging only. Evolve writes refs/canary only. Harbor plus Checkout is the door to refs/active. 多数 Agent 靠把提示词写长来「变聪明」。Yoyo 把 harness 当 Git 对待源码：内容寻址、可变指针、合并前测试、人闸。点赞只写 refs/staging。Evolve 只写 refs/canary。Harbor + Checkout 才是 refs/active 的门。 長いプロンプトで賢く見せない。ハーネスは Git のように扱う。Thumbs は refs/staging のみ。Evolve は refs/canary のみ。refs/active は Harbor と Checkout。

Overview 总览 Overview Walk the parent chain. See what a snapshot actually changed — playbook bullets, loop fields, skills — not a hash list. 顺着 parent 走。看快照到底改了什么：playbook 条目、循环字段、技能。不是一串哈希。 parent を辿る。プレイブック、ループ、スキル。ハッシュ一覧ではない。
Evolve ACE-style grow-and-refine. Never a full rewrite of the playbook. Candidates run Harbor in a detached git worktree, not in your working tree. ACE 式只增补、不整本重写。候选在分离的 git worktree 里跑 Harbor，不动你的工作区。 ACE 式に増やす。全文書き換えない。Harbor は分離 worktree。作業ツリーは触らない。
Harbor Held-in and held-out must not regress. At least one split must improve. Any safety fail blocks promotion. 训练集和留出集都不能退步；至少一侧要进步；安全项失败则禁止晋升。 held-in / held-out は退行禁止。少なくとも一方は改善。安全失敗は昇格を止める。
Promote 晋升 Promote A human checkout. The agent does not move the pointer you trust. 人来 checkout。Agent 不能自己拨你信任的那根指针。 人が checkout する。エージェントは信頼ポインタを動かさない。
L1 Prompts, playbook, skills — after Harbor. 提示词、playbook、技能——过 Harbor 之后。 プロンプト、プレイブック、スキル。Harbor の後。
L2 Signed WASM tools. Unsigned never becomes active. No WASI filesystem. 签名的 WASM 工具。未签名成不了 active。没有 WASI 文件系统。 署名 WASM。未署名は active にならない。WASI FS なし。
L3 Loop / policy topology — human confirmation in the UI or CLI. 循环预设 / 策略拓扑——界面或 CLI 里人确认。 ループ / ポリシー位相。人が UI か CLI で確認。
L4 Go kernel, evaluator, vault, updater keys — nobody. Not the agent. Not evolve. Go 内核、评测器、密钥库、更新器密钥——谁都不许改。Agent 不行，evolve 也不行。 Go カーネル、評価器、保管庫、アップデータ鍵。誰も不可。

Video 视频 ビデオ

A conversation, not a factory console. 它是一场对话，不是八步流水线。 会話であり、工場コンソールではない。

Left rail switches to Video. Short-drama production and an infinite canvas share that surface. They use your keys, your adapters, a separate session channel. Wallpaper covers the product pages; the canvas editor stays opaque so you can see the picture. 左侧切到「视频」：短剧工作台、无限画布，走自己的会话通道，不和写代码的对话搅在一起。模型还是你自己的 Key。产品页可以铺壁纸；画布编辑页故意不铺，那边要干净。 左レールで Video。短編と無限キャンバス。Agent とは別チャネル。キーは自分の。キャンバス編集は壁紙を敷かない。

Create 创作 Create Describe a clip. Generation adapters for image, speech, and video live in Settings — not a second runtime in the page. 描述一段片子。图像、语音、视频适配器在设置里，不在页面里再跑一套 Agent。 クリップを書く。画像・音声・動画アダプタは設定。ページに第二ランタイムはない。
Drama 短剧 Drama Paste a chapter. Map a novel into a confirmable episode plan before shooting. The board is a director desk you open, not a permanent right column. 贴一章小说。先映射成可确认的分集计划，再拍。分集板是按需打开的导播台，不是常驻右栏。 章を貼る。撮影前に話数計画を確認する。ボードは常駐右列ではない。
Canvas 画布 Canvas A spatial workspace for shots. Library and assets stay in the same video chrome. The editor itself is a user workspace, not a product page with wallpaper. 镜头的空间工作区。片库和素材仍在同一套视频壳里。编辑器本身是用户画布，不是铺壁纸的产品页。 ショットの空間ワークスペース。ライブラリも同じクロム。編集器は壁紙を敷かない。

Skills 技能 スキル

Packs stay off until you say so. 技能包默认关，你打开才进会话。 Pack は、あなたが入れるまでオフ。

A skill is a named method the loop may load. A pack is a versioned tree of them — Superpowers is the first. Enabling a pack is a workspace choice, not a per-turn toggle. Session start may preload a bootstrap skill in-process (not identity). Harbor evals never load packs, so a flashy method cannot fake a promote. Optional WASM tools sit behind HighRisk + ForceAsk, with no WASI filesystem. 技能是循环可以加载的具名方法。Pack 是一棵有版本的技能树，Superpowers 是第一棵。启用是工作区选择，不是每一轮的开关。开场可以预载引导技能（不是身份）。Harbor 评测不加载这些包，避免「看起来聪明、实际过不了关」。可选 WASM 工具走 HighRisk + 强制询问，没有 WASI 文件系统。 スキルはループが載せる方法。Pack は版付きの木。Superpowers が最初。有効化はワークスペース単位。Harbor は Pack を読まない。WASM は HighRisk + ForceAsk。WASI FS なし。

Surfaces 三种入口 三つの入口

One core. Desktop, browser, CLI. 同一套核心。桌面、浏览器、命令行。 ひとつのコア。デスクトップ、ブラウザ、CLI。

HTTP + SSE, JSON-RPC on stdio, WebSocket at /api/ws. The GUI is not a second agent. Installers are the desktop app. CLI archives are optional. HTTP + SSE、stdio 上的 JSON-RPC、/api/ws 的 WebSocket。图形界面不是第二套智能体。安装包是桌面应用。CLI 压缩包给命令行用户。 HTTP + SSE、stdio の JSON-RPC、/api/ws。GUI は第二エージェントではない。インストーラはデスクトップ。CLI は任意。

CLI yoyo run, eval, evolve, harness, pack. Same home directory. yoyo run、eval、evolve、harness、pack。同一套 home。 yoyo run / eval / evolve / harness / pack。同じ home。

Wallpaper 壁纸 壁紙

Any photograph. Type still has to read. 随便哪张图。字还得站得住。 どの写真でも。文字は読めたまま。

Settings → Appearance → Wallpaper. No pack store. The agent cannot change this. A veil mixes the palette over the image — or pull it to zero. Large photos downsample on import; they are not rejected for being a 4K phone shot. 设置 → 外观 → 壁纸。没有皮肤商城。Agent 改不了这项。一层压暗让字能读；想看原图，把滑条拉到零。手机拍的大图导入时会缩小，不会弹「图片过大」把你拦回去。 設定 → 外観 → 壁紙。ストアはない。エージェントは触れない。ヴェールで文字を守る。大きな写真は取り込み時に縮小され、拒否されない。

Fit 给谁用 向き

For operators. Not a hosted chat. 给愿意自己填 Key 的人。不是全托管聊天。 操作者向け。托管チャットではない。

Fits 适合 向く

  • You already have an OpenAI-compatible API key. 已经在用 API，OpenAI 兼容的也可以。 OpenAI 互換の API キーを持っている。
  • You want “say” and “change files” in the same window, in a folder you own. 想把「说」和「改文件」放在同一窗口，文件夹是自己的。 話すこととファイル変更を、自分のフォルダで同じ窓にしたい。
  • You want a human gate, a budget cap, and a harness that cannot promote itself. 要人闸、要预算上限、要 harness 不能自己晋升。 人のゲート、予算上限、自己昇格しないハーネスが欲しい。

Does not fit 不适合 向かない

  • You want a fully hosted product and no keys of your own. 想要全托管、不想自己填 Key。 完全托管で、自分のキーを持ちたくない。
  • You want a VS Code fork, a Monaco tab, or a fake IDE. 想要 VS Code 仿制品，或一个假 IDE。 VS Code のフォークや偽 IDE が欲しい。
  • You want the agent to rewrite its own kernel. 想让智能体改自己的内核。 エージェントに自分のカーネルを書かせたい。

Will not 明确不做 やらないこと

Product decisions, not missing checkboxes. 这是产品决定，不是没做完。 未実装ではなく、製品の決定。

  • Fork VS Code, or ship a Monaco tab 去 fork VS Code，或塞一个假 IDE VS Code をフォークしない。Monaco も置かない It is a client of one Go loop. 它是同一条 Go 循环上的客户端。 ひとつの Go ループのクライアント。
  • Let the agent rewrite its Go kernel 让 Agent 改自己的 Go 内核 エージェントに Go カーネルを書かせない Prompts and skills may evolve. Evaluator, vault, and updater cannot. 提示词和技能可以进化。评测器、密钥库、更新器不行。 プロンプトとスキルは進化してよい。評価器・保管庫・アップデータは不可。
  • Pretend a deny-list is a sandbox 把命令黑名单说成沙箱 拒否リストをサンドボックスと呼ばない Isolation is opt-in, and the UI says so. 隔离是可选的，界面会如实写。 隔離は任意。UI は正直に書く。
  • Silently replace the running binary 偷偷覆盖正在运行的程序 実行中のバイナリを黙って置き換えない yoyo update apply stays a human step. yoyo update apply 必须由人执行。 yoyo update apply は人の手順。
  • Stuff the whole repo into the prompt because you typed @ 因为你打了 @ 就把整仓塞进提示词 @ を打っただけでリポジトリ全体を入れない Mentions are bounded injections. 提及是有预算的注入。 メンションは予算つきの注入。
  • A second agent runtime in the frontend 在前端再跑一套智能体 フロントに第二エージェントを置かない No LangChain, no Vercel AI SDK loop, no assistant-ui brain. 没有第二套 LangChain / 前端循环。 LangChain もフロントのループもない。
